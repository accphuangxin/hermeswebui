# Hermes Kanban 使用指南

## 📋 简介

Hermes Kanban 是一个可视化的任务管理系统，用于管理和跟踪 Hermes Agent 的任务执行流程。

## 🚀 快速开始

### 访问 Kanban

1. 启动 111 Hermes 应用
2. 进入 **Hermes Chat** 视图（左侧 Hermes logo）
3. 点击顶部的 **看板** 按钮

### 前置条件

- Hermes Agent 后端服务需要运行在 `http://localhost:8650`
- 确保 Kanban API 已启用（默认随 Hermes Agent 启动）

## 📦 核心功能

### 1. Board（看板）管理

**创建 Board**:
1. 在左侧栏点击 **+** 按钮
2. 填写：
   - **Slug**: 英文标识（例如：`health-family`）
   - **名称**: 看板名称（例如：`家庭健康档案`）
   - **描述**: 可选的说明文字
   - **图标**: 选择一个 emoji 图标
3. 点击 **创建**

**切换 Board**:
- 在左侧栏点击任意 Board 名称即可切换

### 2. Task（任务）管理

#### 创建任务

1. 选择一个 Board
2. 点击顶部的 **+ 新建任务** 按钮
3. **步骤 1 - 基本信息**：
   - **标题**: 任务名称（必填）
   - **描述**: 详细说明（可选）
   - **分配给**: 选择一个 Hermes Agent 执行
   - **优先级**: 0-10 的数字
4. **步骤 2 - 依赖关系**（可选）：
   - 勾选此任务依赖的父任务
   - 只有父任务完成后，此任务才会开始执行
5. 点击 **创建任务**

#### 查看任务详情

1. 在看板中点击任意任务卡片
2. 右侧面板显示完整信息：
   - 基本信息（ID、分配者、优先级、时间）
   - 依赖关系（父任务、子任务）
   - 任务描述
   - 执行结果（完成后）

#### 任务操作

**编辑任务**:
- 在详情面板点击 **编辑** 按钮（即将实现）

**删除任务**:
- 在详情面板点击 **删除** 按钮
- 确认后任务将被永久删除

**重试失败任务**:
- 对于 `failed` 状态的任务，点击 **重试** 按钮
- 任务状态将重置为 `ready`，等待重新执行

### 3. 任务状态

Kanban 看板分为 5 列，对应任务的不同状态：

| 状态 | 说明 | 颜色 |
|------|------|------|
| **准备就绪** (ready) | 无依赖或所有依赖已完成，等待执行 | 🔵 蓝色 |
| **执行中** (running) | Agent 正在执行此任务 | 🟡 黄色 |
| **等待中** (blocked) | 依赖的父任务尚未完成 | ⚪ 灰色 |
| **已完成** (done) | 任务成功完成 | 🟢 绿色 |
| **失败** (failed) | 任务执行失败 | 🔴 红色 |

### 4. 依赖关系管理

**Parent-Child 链接**:
- **Parent（父任务）**: 必须先完成的前置任务
- **Child（子任务）**: 依赖父任务的后续任务

**示例流程**:
```
数据分析 (ready) → 风险评估 (blocked) → 用药建议 (blocked)
                                            ↓
生活方式改善 (ready) ────────────────────→ 综合报告 (blocked)
```

**依赖规则**:
- 子任务会自动标记为 `blocked` 状态
- 当所有父任务完成后，子任务自动变为 `ready`
- Daemon 会自动调度 `ready` 状态的任务执行

## 🔄 实时更新

- 任务状态每 **5 秒** 自动刷新
- 无需手动刷新即可看到最新状态
- 点击顶部 **刷新** 按钮可立即更新

## 💡 使用技巧

### 复杂任务拆解

对于复杂任务，建议拆解为多个子任务：

1. **识别步骤**: 将大任务分解为独立的小步骤
2. **定义依赖**: 确定哪些步骤必须先完成
3. **分配 Agent**: 为每个步骤选择合适的 Agent
4. **设置优先级**: 重要任务设置较高优先级

**示例**：年度体检评估

```
主任务: 张三年度体检评估
├─ 子任务 1: 数据分析（血脂、血糖、肝功能）
├─ 子任务 2: 风险评估（依赖任务 1）
├─ 子任务 3: 用药建议（依赖任务 2）
└─ 子任务 4: 生活方式改善（独立，可并行）
```

### 任务卡片信息

任务卡片上显示：
- **标题**: 任务名称
- **优先级**: P0-P10 标签（橙色）
- **分配者**: Agent 名称（人形图标）
- **依赖数量**: 
  - ↑ 父任务数量
  - ↓ 子任务数量
- **开始时间**: 时钟图标
- **任务 ID**: 底部灰色小字

### 空状态处理

**无看板**:
- 点击中央的 **创建看板** 按钮开始

**无任务**:
- 每列显示"暂无任务"提示
- 点击顶部 **+ 新建任务** 创建第一个任务

## 🐛 故障排除

### 无法连接到 Kanban API

**问题**: "HTTP 404: Not Found" 或连接错误

**解决方案**:
1. 确认 Hermes Agent 正在运行
2. 检查端口 8650 是否被占用：
   ```bash
   lsof -i :8650
   ```
3. 验证 Kanban API 是否启用：
   ```bash
   curl http://localhost:8650/v1/boards
   ```

### 任务一直停在 blocked 状态

**原因**: 父任务尚未完成或依赖关系配置错误

**解决方案**:
1. 查看任务详情中的"依赖任务"列表
2. 确认所有父任务是否已完成
3. 如果配置错误，删除任务重新创建

### 任务自动刷新不工作

**原因**: 浏览器后台标签页可能被限制

**解决方案**:
1. 将 111 Hermes 窗口保持在前台
2. 手动点击 **刷新** 按钮
3. 重启应用

## 📚 API 参考

所有 Kanban 操作都通过 Tauri commands 调用后端 API（端口 8650）。

### Board API

- `listKanbanBoards()` - 列出所有看板
- `createKanbanBoard(input)` - 创建看板
- `getKanbanBoard(slug)` - 获取看板详情

### Task API

- `listKanbanTasks(boardSlug)` - 列出任务
- `createKanbanTask(boardSlug, input)` - 创建任务
- `updateKanbanTask(boardSlug, taskId, input)` - 更新任务
- `deleteKanbanTask(boardSlug, taskId)` - 删除任务
- `getKanbanTask(boardSlug, taskId)` - 获取任务详情

### Dependency API

- `linkKanbanTasks(boardSlug, parentId, childId)` - 建立依赖
- `getTaskParents(boardSlug, taskId)` - 获取父任务
- `getTaskChildren(boardSlug, taskId)` - 获取子任务
